# Сервис объявлений

Консольное приложение для публикации, поиска и управления
частными объявлениями о продаже товаров и услуг.

## Назначение
Позволяет пользователям размещать объявления, находить чужие
объявления по названию и категории, отслеживать статус своих
объявлений и снимать их с публикации.

## Целевая аудитория
Частные лица, желающие быстро продать/купить товар или
предложить услугу без посредников.

## Предметная область
Онлайн-платформа объявлений: каждый пользователь может
публиковать объявления, относящиеся к определённой категории,
просматривать и фильтровать объявления других пользователей.

## Основные сущности
- Пользователь (user) — имя автора объявления
- Объявление (ad) — id, название, категория, цена, автор,
  дата публикации, статус
- Категория (category) — тематическая группа объявления

## Объектная модель
Начиная с ПР3 сущности предметной области представлены классами
(модуль `ads.py`), а данные — объектами этих классов.

| Класс      | Атрибуты | Методы |
|------------|----------|--------|
| `User`     | `name` | `__init__`, `__str__`, `has_name()` — сравнение имени без учёта регистра |
| `Category` | `name` | `__init__`, `__str__`, `has_name()` — сравнение названия без учёта регистра |
| `Ad`       | `id`, `title`, `category: Category`, `price`, `seller: User`, `publish_date`, `is_active`; константа `MAX_ACTIVE_DAYS = 30` | `__init__` (с проверкой данных), `__str__`, свойство `status`, `get_status()`, `deactivate()`, `matches_title()`, `belongs_to()`, `is_sold_by()`, `to_dict()`, `from_dict()` |

### Взаимодействие объектов
- объявление `Ad` содержит ссылки на объекты `Category` и `User`;
- `Ad.belongs_to()` делегирует проверку объекту `Category`,
  а `Ad.is_sold_by()` — объекту `User` (метод `has_name()`);
- `Ad.__str__()` использует строковые представления категории
  и продавца;
- `Ad.to_dict()` / `Ad.from_dict()` преобразуют объект в словарь
  для JSON и обратно, создавая вложенные объекты `User` и `Category`.

### Что осталось обычными функциями
Операции над коллекцией объявлений (`add_ad`, `find_ads`,
`filter_ads_by_category`, `find_ads_by_seller`, `filter_ads_by_price`,
`sort_ads_by_price`, `find_ad_by_id`, `deactivate_ad`, `get_stats`),
работа с файлами (`storage.py`) и безопасный ввод (`utils.py`) не
относятся к отдельному объекту, поэтому остались функциями.
Коллекции работают со списком объектов `list[Ad]`.

Некорректные данные (пустое имя, отрицательная цена, неверный id)
отклоняются конструкторами с исключением `ValueError`; меню
перехватывает его и выводит сообщение об ошибке.

## Возможности
- просмотр всех объявлений;
- поиск объявлений по подстроке в названии;
- фильтрация объявлений по категории;
- сортировка объявлений по цене;
- просмотр объявлений конкретного продавца;
- добавление нового объявления;
- снятие объявления с публикации;
- статистика: количество и средняя цена активных объявлений;
- автоматическое определение статуса объявления (активно /
  снято с публикации / срок истёк) на основе даты публикации;
- данные сохраняются между запусками в JSON-файле.

## Формат хранения данных
Объявления хранятся в `data/ads.json` в виде списка словарей.
При загрузке каждый словарь превращается в объект `Ad`
(`Ad.from_dict`), при сохранении — обратно в словарь (`Ad.to_dict`).
Некорректные записи пропускаются с сообщением, ошибки записи файла
не приводят к аварийному завершению программы.
```json
{
  "id": 1,
  "title": "Продам горный велосипед",
  "category": "Транспорт",
  "price": 15000,
  "seller_name": "Иван Петров",
  "publish_date": "2026-09-01",
  "is_active": true
}
```
