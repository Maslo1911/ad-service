# Сервис объявлений

## Назначение
Веб-приложение для размещения, поиска и управления частными объявлениями
(продажа и покупка товаров, услуг). Позволяет пользователям публиковать
объявления, просматривать чужие объявления по категориям и связываться
с автором объявления.

## Целевая аудитория
Частные лица, желающие быстро продать/купить товар или предложить услугу
без посредников, а также покупатели, ищущие товары и услуги в своём городе.

## Предметная область
Онлайн-платформа объявлений (по аналогии с классифайд-сервисами): каждый
пользователь может публиковать объявления, относящиеся к определённой
категории, редактировать и снимать их с публикации, а также просматривать
и фильтровать объявления других пользователей.

## Основные сущности
- Пользователь (user)
- Объявление (ad)
- Категория (category)

## Основные функции
- регистрация и авторизация пользователей
- создание, редактирование и удаление объявления
- просмотр списка объявлений с фильтрацией по категории
- изменение статуса объявления (активно / снято с публикации)
- просмотр карточки конкретного объявления

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных для хранения объявлений и пользователей;
- реализация полноценной модели пользователей и авторизации;
- разработка REST API для мобильных и сторонних клиентов;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD для автоматической сборки и деплоя.
